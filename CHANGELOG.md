# Changelog – Pardona's UI

Changes to Pardona's UI, written for players. The full guide is in the [handbook](https://pardonas-addons.de/ui/).

## Unreleased

### Added
- Square minimap with a purple-gold frame; the zone name, the small buttons at the minimap and the clock in the Pardona look (beta)
- Fine gold borders for buff icons; debuffs keep the colour of their type (beta)
- Settings page "UI" under "Pardona's Addons": switch every module on or off at any time, no reload needed
- Chat command /pui opens the settings, /pui help lists all commands
